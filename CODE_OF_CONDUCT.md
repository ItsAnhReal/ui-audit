# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good intent, and keep discussions about the work.

To report unacceptable behaviour, contact the maintainer [@ItsAnhReal](https://github.com/ItsAnhReal) privately on GitHub; if nothing else fits, a [private advisory](https://github.com/ItsAnhReal/ui-audit/security/advisories/new) reaches only the maintainer. Reports are handled confidentially.
